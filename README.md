# Map-Making Guide: Everything Human-Made

A research-based guide to placing human-made features on a fantasy map: settlements, population sizes, capitals, borders, castles and military outposts, trade routes, villages and farmland, industry, religious sites and ruins.

It follows real history from the medieval to late-medieval period (c. 1000–1500), with notes for the 1500s–1600s. A separate chapter covers how magic, monsters and other races change the rules.
